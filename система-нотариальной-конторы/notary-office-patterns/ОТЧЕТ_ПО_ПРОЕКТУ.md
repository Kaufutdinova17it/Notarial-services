# Паттерны проектирования в системе нотариальной конторы

## Порождающие паттерны

### 1. Builder (Строитель)

Пошагово создаёт заявку: добавляет клиента, выбранную услугу, описание и исходные документы. Перед созданием проверяет обязательные поля и устанавливает статус «Создана».

**Класс:** `ApplicationBuilder`.

```java
Application application = new ApplicationBuilder()
        .forClient(client)
        .withService(service)
        .withNote(note)
        .attachSourceDocument("passport.pdf")
        .build();
```

### 2. Factory Method (Фабричный метод)

Создаёт уведомления разных типов в зависимости от события: создание заявки, изменение статуса, готовность документов, отклонение или отмена. Каждая фабрика формирует свой текст сообщения.

**Классы:** `NotificationFactory` и конкретные фабрики уведомлений.

```java
Notification notification = NotificationFactory
        .forEvent(event.getType())
        .createNotification(application, client);
```

Выбор конкретной фабрики:

```java
return switch (eventType) {
    case APPLICATION_CREATED -> new ApplicationCreatedNotificationFactory();
    case STATUS_CHANGED -> new StatusChangedNotificationFactory();
    case DOCUMENTS_READY -> new DocumentsReadyNotificationFactory();
    case APPLICATION_REJECTED -> new ApplicationRejectedNotificationFactory();
    case APPLICATION_CANCELLED -> new ApplicationCancelledNotificationFactory();
};
```

### 3. Singleton (Одиночка)

Обеспечивает единую точку доступа к подключению базы данных H2. При первом обращении создаёт подключение и инициализирует схему базы.

**Класс:** `Database`.

```java
public static Database getInstance() {
    if (instance == null) {
        synchronized (Database.class) {
            if (instance == null) {
                instance = new Database();
            }
        }
    }
    return instance;
}
```

## Структурные паттерны

### 4. Adapter (Адаптер)

Согласует интерфейс платёжного сервиса приложения с внешней платёжной заглушкой. Преобразует сумму из рублей в копейки, а числовой код ответа — в объект результата платежа.

**Классы:** `PaymentGateway`, `PaymentStubAdapter`, `ExternalPaymentStub`.

```java
@Override
public PaymentResult pay(Long applicationId, BigDecimal amountRubles) {
    long amountKopecks = amountRubles.movePointRight(2).longValueExact();
    int code = externalPaymentStub.makePayment(
            amountKopecks, "APP-" + applicationId);
    if (code == ExternalPaymentStub.CODE_SUCCESS) {
        return PaymentResult.success(externalPaymentStub.lastTransactionId());
    }
    return PaymentResult.failure(externalPaymentStub.describeCode(code));
}
```

### 5. Decorator (Декоратор)

Расширяет отправку уведомлений дополнительными возможностями без изменения основного отправителя. Добавляет журналирование и повторные попытки при ошибке отправки.

**Классы:** `EmailNotificationSender`, `LoggingNotificationSender`, `RetryNotificationSender`.

```java
NotificationSender sender = new RetryNotificationSender(
        new LoggingNotificationSender(emailSender), 3);
```

Фрагмент повторной отправки:

```java
try {
    delegate.send(notification, emailAddress);
    return;
} catch (RuntimeException e) {
    if (attempt >= maxAttempts) {
        throw e;
    }
}
```

### 6. Facade (Фасад)

Предоставляет единый простой интерфейс для работы с приложением. Объединяет обращения к сервисам клиентов, услуг, заявок, документов, платежей и уведомлений, скрывая их внутреннее взаимодействие.

**Класс:** `NotaryOfficeFacade`.

```java
public Application submitApplication(long clientId, long serviceId,
                                     String note, String... documents) {
    Client client = clientService.findById(clientId);
    Service service = catalogService.findById(serviceId);

    ApplicationBuilder builder = new ApplicationBuilder()
            .forClient(client)
            .withService(service)
            .withNote(note);
    return applicationService.createApplication(builder);
}
```

## Поведенческие паттерны

### 7. Observer (Наблюдатель)

Оповещает подписчиков о создании заявки или изменении её статуса. `NotificationService` формирует уведомление, а `AuditLogListener` записывает событие в журнал аудита.

**Классы:** `ApplicationEventPublisher`, `ApplicationListener`, `NotificationService`, `AuditLogListener`.

```java
public void publish(ApplicationEvent event) {
    for (ApplicationListener listener : listeners) {
        listener.onApplicationEvent(event);
    }
}
```

Публикация события после создания заявки:

```java
eventPublisher.publish(new ApplicationEvent(
        ApplicationEventType.APPLICATION_CREATED,
        application.getId(), application.getClientId(),
        "заявка создана"));
```

### 8. State (Состояние)

Управляет жизненным циклом заявки и проверяет допустимость изменения статуса. Например, заявка может перейти из «Создана» в «В процессе», а завершённая заявка не может снова вернуться в обработку.

**Классы:** `ApplicationStateMachine`, `CreatedState`, `InProgressState`, `ReadyState`, `TerminalState`.

```java
public ApplicationStatus transitionTo(ApplicationStatus target) {
    currentState.ensureTransitionAllowed(target);
    currentState = stateOf(target);
    return target;
}
```

Допустимые переходы новой заявки:

```java
@Override
public Set<ApplicationStatus> getAllowedTransitions() {
    return Set.of(ApplicationStatus.IN_PROGRESS,
                  ApplicationStatus.CANCELLED);
}
```

### 9. Strategy (Стратегия)

Выбирает алгоритм расчёта стоимости услуги: фиксированный тариф, процент от суммы сделки или льготный тариф со скидкой. Алгоритм определяется во время выполнения по типу услуги.

**Классы:** `PricingStrategy`, `FixedPricingStrategy`, `PercentagePricingStrategy`, `PrivilegedDiscountStrategy`.

```java
PricingStrategy strategy = PricingStrategy.forPricingType(
        service.getPricingType());
BigDecimal amount = strategy.calculate(service, context);
```

Выбор стратегии:

```java
return switch (type) {
    case FIXED -> new FixedPricingStrategy();
    case PERCENTAGE -> new PercentagePricingStrategy();
    case PRIVILEGED -> new PrivilegedDiscountStrategy();
};
```
